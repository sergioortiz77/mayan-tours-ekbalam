# Mayan Tours Ek Balam - Web App (Next.js / React)

Aplicación web moderna, responsiva y multilingüe para el proyecto turístico **Mayan Tours Ek Balam** y su guía oficial certificado **Jesús Alfredo Chan Chan**.

## 🌟 Características Principales
- **Framework:** Next.js 14 (App Router) + React 18 + TypeScript.
- **Estilos:** Tailwind CSS con diseño inspirado en la cultura maya (tonos tierra, ámbar y verde jade).
- **Multilingüe (i18n):** Selector dinámico e instantáneo en 3 idiomas: Español (`ES`), Inglés (`EN`) y Francés (`FR`), con mención al Maya Yucateco.
- **Conversión Directa:** Botones de reservación por WhatsApp con mensajes pre-cargados según el tour o taller seleccionado.
- **Módulos Integrados:**
  1. **Hero & Certificaciones:** Acreditación SECTUR NOM-08, 12 años de trayectoria.
  2. **Perfil del Guía & Turismo Comunitario:** Historia y valor compartido para la comunidad de Ek Balam.
  3. **Tours Arqueológicos:** Recorrido guiado por la zona arqueológica de Ek Balam.
  4. **Talleres Tradicionales:** Urdido de hamaca, bordado maya, cacao ancestral y ceremonia en parcela/milpa.
  5. **Transporte Privado en Van:** Volkswagen Transporter con aire acondicionado y rutas turísticas.
  6. **Servicios Complementarios:** Cabañas, hospedaje comunitario y venta de artesanías.
  7. **Guía Práctica del Visitante:** Tarifas oficiales INAH/CULTUR, recomendaciones de calzado/vestimenta y políticas SPEI.
  8. **Preguntas Frecuentes (FAQ):** Acordeón interactivo.
  9. **Botón Flotante de WhatsApp:** Acceso rápido para atención directa desde cualquier sección.

## 🚀 Cómo ejecutar localmente

1. Clonar o copiar la carpeta del proyecto:
```bash
cd mayan-tours-ekbalam
```

2. Instalar dependencias:
```bash
npm install
# o
yarn install
# o
pnpm install
```

3. Iniciar el servidor de desarrollo:
```bash
npm run dev
```

4. Abrir [http://localhost:3000](http://localhost:3000) en el navegador.

## 📦 Despliegue en Producción
Se puede desplegar en 1 clic en:
- **Vercel**: Importar el repositorio de GitHub y seleccionar Next.js.
- **Netlify**: Conectar repositorio o arrastrar la carpeta construida tras `npm run build`.
- **Cloudflare Pages / AWS Amplify**: Compatible directamente.
